# 题库与出题约束

每题控制在约 30 分钟，并优先使用真实工程场景。

长期递进覆盖：

- C++ 对象生命周期、RAII、移动语义、模板和内存模型、多线程、无锁编程、通信
- 数组、链表、栈、队列、堆、哈希表、树和图
- 递归、回溯、BFS、DFS、拓扑排序、最短路
- 贪心和动态规划
- 缓存局部性、数据布局、复杂度和工程边界条件

## 1. 数据结构与资源管理

- ECS、实体句柄与 generation 校验
- 对象池、内存池、空闲链表
- 连续存储、稀疏集合（Sparse Set）、句柄到数据的映射
- 环形缓冲区、渲染命令队列
- 资源生命周期、引用计数与延迟释放
- 缓存淘汰：LRU、LFU、带容量或成本约束的缓存
- 内存碎片、对齐与简单分配策略

## 2. 数据布局与访存优化

- AoS、SoA、AoSoA 布局及转换
- 缓存局部性、遍历顺序与工作集大小
- 矩阵转置、分块计算与数据复用
- 连续访问、跨步访问、间接访问
- 伪共享与线程局部数据布局
- 数据压缩、位图与位操作
- 减少临时数组、数据复制与重复访存

## 3. 并发编程与任务调度

- 互斥锁、条件变量与生产者—消费者
- 原子操作、内存序与 happens-before
- SPSC 队列、无锁结构的局部实现与错误分析
- ABA 问题与并发内存回收的基础分析
- Job System、任务粒度与批量提交
- 静态划分、动态调度与负载均衡
- 工作窃取的简化模型
- CPU/GPU 同步、Fence 与资源复用时机

## 4. 图算法与依赖管理

- Render Graph、依赖建模与拓扑排序
- 循环依赖检测
- 任务 DAG、关键路径与并行度分析
- 资源依赖与读写冲突检测
- 资源生命周期区间与内存复用
- 增量更新、脏标记与依赖传播

## 5. 空间算法与几何计算

- AABB、射线相交与包围体测试
- BVH 的构建、遍历与更新
- 均匀网格、空间哈希与邻域查询
- 视锥剔除与可见对象筛选
- Morton 编码与空间排序
- 粒子邻居搜索与碰撞候选对生成

## 6. 并行算法与批量数据处理

- Reduction：求和、最值、统计量
- Scan：前缀和与偏移量生成
- Stream Compaction：有效元素压缩
- Histogram：直方图与局部统计合并
- Scatter/Gather：数据分发与收集
- 分桶、计数排序与基数排序的局部步骤
- 批量去重、分组与分段归约
- 使用上述算法组织可见对象、粒子或稀疏任务

## 7. CPU 计算与 SIMD

- 自动向量化及编译器报告分析
- 循环依赖、指针别名与向量化障碍
- SIMD 的基础实现与尾部元素处理
- 分支处理、掩码计算与数据筛选
- 单线程与多线程计算的规模分界
- OpenMP 的循环并行、归约与调度

## 8. GPU / CUDA 计算

- 线程、线程块与数据索引映射
- 合并访存与跨步访问优化
- Shared Memory 分块与数据复用
- Bank Conflict 的识别与修正
- Warp Shuffle 与块内归约
- 原子操作争用与局部聚合
- 分支发散与工作分组
- 寄存器、共享内存占用与并行度取舍
- Kernel 融合与中间结果访存
- 数据传输、异步执行与双缓冲

## 9. 数值计算与科学计算

- 浮点误差、求和顺序与数值稳定性
- 成对求和、Kahan 求和与并行归约误差
- 稠密矩阵运算的简化实现
- CSR/COO 稀疏存储与稀疏矩阵乘向量
- Stencil：网格邻域更新与边界处理
- Jacobi 等迭代方法的单步实现与收敛判断
- 粒子系统的简单数值积分
- 随机采样、Monte Carlo 估计与误差观察

## 10. 分区、通信与规模扩展

- 数据分区、域分解与负载均衡
- Halo Exchange：邻接分区边界交换
- 消息打包、缓冲区布局与通信量估算
- MPI 的基础点对点通信与集体通信
- 通信与计算重叠
- 强扩展、弱扩展与并行效率
- NUMA 数据放置与访问成本的基础分析

## 11. 搜索、回溯与动态规划

- Shader Variant 组合生成与约束剪枝
- 资源配置搜索与合法方案枚举
- 显存预算、资源选择与背包问题
- 批处理划分与成本最小化
- 任务分配的简化优化问题
- 用记忆化搜索消除重复计算

## 12. 性能分析与工程验证

- 基准测试：预热、重复测量与计时范围
- 运算量、访存量与算术强度估算
- 有效带宽、吞吐量与延迟
- Roofline 思路与瓶颈判断
- Amdahl 定律与加速上限
- 使用 profiler 验证性能假设
- 正确性参考实现、边界条件与浮点误差容限
- 分析“优化后为什么没有变快”
