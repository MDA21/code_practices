# 出题模板

提交前不得给出完整实现、核心循环或可直接拼成答案的伪代码。

```markdown
# [题目名称]

## 背景和目标
[真实引擎 / HPC 场景，一句话核心知识点]

## 指定接口
[头文件、类型、函数签名。只给契约，不给实现]

## 行为示例
[2-4 个输入/输出或状态变化例子]

## 明确约束
[允许 / 不允许的 API、内存、线程、依赖]

## 复杂度目标
- 时间：
- 空间：

## 必测边界情况
- [ ]
- [ ]
- [ ]

## 验收问题
- [学员必须能回答的 2-3 个问题，用来检查理解而不是背答案]

## 提示
- [少量提示，不泄露核心解法]
```
